# Eluvio O

This is Silver Trak's neglected fork of the actively maintained [Eluvio O](https://github.com/eluv-io/elv-o).

elv-o provides a batch job interface to upload and interact with video asset renditions stored in [Content Fabric].
via a typical REST HTTP API.

[Content Fabric]: https://docs.eluv.io/api/content-fabric/content-fabric-api/
